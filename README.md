# 3Dノックダウンシューター (Knockdown Shooter 3D)

海に浮かぶイカダの上に積まれたブロックを、パチンコ（スリングショット）式の発射台からボールを撃って全部叩き落とす、ブラウザで遊べる3D物理ゲームです。

- **プレイ**: `index.html` をブラウザで開くだけ（ライブラリは CDN から読み込みます。初回のみインターネット接続が必要）
- **動作環境**: モダンブラウザ（PC / スマートフォン対応、タッチ操作可）
- **技術**: Three.js 0.158.0（描画） + cannon.js 0.6.2（物理演算）、単一ページ構成（`index.html` + `game.js`）

## 遊び方

1. 画面を**下にドラッグ**して引っ張り、離すとボールが発射されます（引くほど強いショット）
2. イカダの上のターゲットを**全部落として水に沈めれば**ステージクリア。残りボール数 × 30点のボーナスが入ります
3. ボールが尽きるまでに落としきれないと失敗（スコアはステージ開始時に戻ります）
4. 全6ステージ

## 操作

| 操作 | 動作 |
|---|---|
| ドラッグ（下方向）→離す | 狙って発射（軌道プレビュー表示） |
| ◀ ▶ ボタン / ← → キー（長押し） | 発射台がターゲットの周りを滑らかに回転（±90°・真横まで） |
| スペースキー / 📷 カメラボタン | カメラ切替（後方 / 横 / 俯瞰） |
| ボールを戻す | 発射前のボール位置リセット（飛行中は投げ直し） |
| 🔁 やり直す | ステージを最初から |

## ルール・スコア

- 木箱 **10点** / 缶 **15点** / 板 **20点** / ボムブロック **30点**
- ターゲットが水に落ちると水しぶきとともに消えて得点になります
- **ボムブロック**（黒＋赤い帯＋導火線、ステージ4〜6に登場）: 強い衝突で爆発し、半径約2.9以内のブロックとボールを吹き飛ばします。近くのボムは連鎖爆発します
- ステージクリア時: 残りボール × 30点ボーナス

## 演出・仕組み

- 海面はミラー反射（反射用カメラでシーンを再描画し、波紋で歪ませて合成）。空は実ジオメトリのスカイドーム
- 発射するとカメラがボールを追いかけるチェイスカメラ。ステージ開始時は積み上げのクローズアップから引いていくイントロ演出
- 水に落ちた物体は大きさに応じた水柱・しぶき・リングとサウンド付きで消えます
- 効果音は Web Audio のシンセサイズ生成（アセットファイルなし）
- 物理の安定化: 静的ボディの取りこぼしを避けるため broadphase は NaiveBroadphase を使用（詳細は `docs/HANDOFF.md`）
