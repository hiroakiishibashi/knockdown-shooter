## 実装上の注意（踏んだ罠）

1. **broadphase は NaiveBroadphase 固定**。SAP にするとステージ開始後に追加した静的イカダを取りこぼし、積み上げが落下する（実害が出て切り替えた）。
2. **反射の歪みは2枚の波紋テクスチャの「差分」を使う**。単独テクスチャの値で歪ませると平均値ぶん反射像が系統的にずれる。
3. **反射範囲外のサンプルは深水色に落とさない**。飽和した青が左右の端に「板」として出る。淡い空色ヘイズへ広い帯（±0.12）でフェードさせること。縦画面では特に目立つ。
4. **反射ターゲットには mipmap 必須**。無いと浅い角度で反射像が横に流れる（にじみ）。
5. **背景は scene.background のテクスチャではなくスカイドーム（実ジオメトリ）**。反射パスは画面空間背景を正しい方向に写せない。
6. **爆発は collide コールバック内で実行しない**。`detonate` フラグ → 物理ステップ後に `explodeBomb()`。連鎖は `gone` フラグで二重発火防止。
7. **ステージ配置を変えたら必ずヘッドレス物理シムで自己崩壊チェック**（実ページと同じ接触マテリアル・配置計算で数秒回し、ドリフトと沈下を見る）。ボム配置では「ピラミッド脇に置くと隣の木箱と干渉して自爆する」問題をこの検証で検出した（→ 上部配置に変更）。
8. 発射台の周回中心はステージのイカダ重心。半径は正面位置が z=7.0 になるよう `7.0 - stageCenter.z` で決める。

## 既知の制限・今後の候補

- ライブラリは CDN 依存（オフライン初回起動不可）。ポータル掲載版ではポータル側の同梱方針に従う
- ランキング（ポータル共通ランキング）未接続。接続する場合はポータル側の `game_catalog` 登録と `tools/new-game-check.mjs` の確認が必要
- 効果音は全て合成音。差し替える場合は Web Audio のまま音色調整が無難
- ステージ追加は `game.js` の `STAGES` に build 関数を足すだけ。検証（7.）を忘れずに
